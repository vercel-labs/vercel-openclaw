OpenClaw with Vercel Drives

A test deployment for running OpenClaw in fresh sandboxes with saved conversations, files and memory on a Drive.

The HTTP API requires a control token. Submit messages to POST /api/messages and check saved outcomes at GET /api/requests.

The optional Slack test adapter preserves the event body and queues work before acknowledgement. Two Slack turns verified saved state across fresh VMs. Live readiness tests verified reuse of the same VM and gateway, and a hosted delayed callback verified idle shutdown. User-message warm latency, eyes acknowledgment and a full one-hour idle interval still need verification. Continuous operation and automatic recovery after an interrupted turn are not guaranteed.
